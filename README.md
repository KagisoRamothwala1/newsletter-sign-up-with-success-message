Newsletter Sign-Up Form
Overview
This project is a responsive newsletter sign-up form that allows users to subscribe to a monthly newsletter by entering their email address.

Once the form is successfully submitted, a confirmation message appears to thank the user for subscribing.

Features
Responsive design for desktop and mobile devices.

Email input field with validation.

Submit button to process the subscription.

Success message displayed after successful submission.

Dismiss button to close the confirmation message.

Built With
HTML5

CSS3

JavaScript

What I Learned
Through this project, I practised working with HTML forms, CSS styling and JavaScript DOM manipulation. I also improved my understanding of form validation, event listeners and displaying dynamic confirmation messages.
